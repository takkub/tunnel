# UI review · tunnel-manager (web) · 2026-06-20

## 📸 Scope
Admin console จัดการ Cloudflare tunnels (theme zinc/orange dark). รีวิว 7 views × desktop+mobile หลังเพิ่ม 2 หน้าใหม่ (Nginx reverse proxy generator, Docker panel), แก้ Create modal (domain dropdown), Settings (domains section) และลบหน้า DNS. เป้าหมาย: ตรวจ Nielsen heuristics + mobile responsive + visual hierarchy/consistency ระหว่างหน้าใหม่กับหน้าเดิม แล้วเสนอแก้ที่ frontend สั่งทำได้เลย (มี file:line + class). ต่อยอดจาก 8 จุดที่ QA เจอ — ขุดให้ลึกกว่า ไม่ซ้ำเฉยๆ.

## ✅ ของดีที่ควรเก็บไว้
- Theme zinc/orange สม่ำเสมอ, card `rounded-2xl` + `border-zinc-800` ทุกหน้า
- มี skeleton loader จริง (nginx `animate-pulse`, docker `h-16` placeholder) + error state (docker)
- Status badge (running/exited/stopped) อ่านง่าย ใช้สี emerald/zinc คงเส้นคงวา
- `Button.tsx` มี `min-h-[48px]` + disabled state ที่ "ตายชัด" (`bg-zinc-800 text-zinc-600`) — เป็น pattern ที่ถูกต้องอยู่แล้ว (ปัญหาคือ inline button ไม่ได้ใช้ตามนี้ → ดูข้อ R1)
- Input `focus-within:border-orange-500/60` — affordance focus ชัด
- Create modal มี live preview hostname (`→ myapp.sabuytube.xyz`) ดีมาก

## 🚩 Heuristic violations (Nielsen)
- **#1 Visibility of system status** — docker log ไม่ autoscroll + ไม่มี state "เชื่อมต่อไม่สำเร็จ" (R9); badge `docker` ไม่บอกว่าคืออะไร (R8)
- **#4 Consistency & standards** — disabled treatment ไม่ตรงกันระหว่าง `Button.tsx` กับ inline button (R1); stop สองภาษาสี (R11); search/filter มีที่ dashboard แต่ไม่มีที่ docker (R5)
- **#6 Recognition rather than recall** — docker mobile ชื่อ container หาย ต้องเดา (R4)
- **#7 Flexibility & efficiency** — ไม่มี search ใน 30+ container (R5); ไม่มี copy log (R9)
- **#8 Aesthetic & minimalist** — dashboard 3 ปุ่มสีจัดแข่งกัน ไม่มี focal point (R7)
- **#5 Error prevention** — create modal mobile เห็น domain ไม่ครบ → เสี่ยงสร้างผิด domain (R2)

## 🎯 Recommended next steps (สำหรับ Lead) — Top 5 high-impact
1. **[high] delegate frontend → R1**: standardize disabled state (inline button → ใช้ `<Button>` หรือ dead-zinc) — `nginx/page.tsx:157`, `settings/page.tsx`, `CreateTunnelModal.tsx`
2. **[high] R2**: fix suffix overflow — `CreateTunnelModal.tsx:132` เพิ่ม `min-w-0`, L134 เพิ่ม `flex-shrink-0`
3. **[high] R4 + R5**: docker mobile stack layout (`docker/page.tsx:161`) + เพิ่ม search/filter reuse pattern จาก `page.tsx:181`
4. **[high] R3**: Export bundle → primary orange + icon (`nginx/page.tsx:173`)
5. **[high] R6**: sidebar backdrop scrim (`client-layout.tsx`)

> R7–R10 (med) ทำรอบถัดไป: dashboard bulk hierarchy, badge context, docker-log autoscroll/copy, refresh icon button.
