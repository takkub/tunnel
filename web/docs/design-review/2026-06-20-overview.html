UI review · tunnel-manager (web) · 2026-06-20

📸 Scope

Admin console จัดการ Cloudflare tunnels (theme zinc/orange dark). รีวิว 7 views × desktop+mobile หลังเพิ่ม 2 หน้าใหม่ (Nginx reverse proxy generator, Docker panel), แก้ Create modal (domain dropdown), Settings (domains section) และลบหน้า DNS. เป้าหมาย: ตรวจ Nielsen heuristics + mobile responsive + visual hierarchy/consistency ระหว่างหน้าใหม่กับหน้าเดิม แล้วเสนอแก้ที่ frontend สั่งทำได้เลย (มี file:line + class). ต่อยอดจาก 8 จุดที่ QA เจอ — ขุดให้ลึกกว่า ไม่ซ้ำเฉยๆ.

✅ ของดีที่ควรเก็บไว้

  • Theme zinc/orange สม่ำเสมอ, card rounded-2xl + border-zinc-800 ทุกหน้า
  • มี skeleton loader จริง (nginx animate-pulse, docker h-16 placeholder) + error state (docker)
  • Status badge (running/exited/stopped) อ่านง่าย ใช้สี emerald/zinc คงเส้นคงวา
  • Button.tsx มี min-h-[48px] + disabled state ที่ "ตายชัด" (bg-zinc-800 text-zinc-600) — เป็น pattern ที่ถูกต้องอยู่แล้ว (ปัญหาคือ inline button ไม่ได้ใช้ตามนี้ → ดูข้อ R1)
  • Input focus-within:border-orange-500/60 — affordance focus ชัด
  • Create modal มี live preview hostname (→ myapp.sabuytube.xyz) ดีมาก
