# UI review · tunnel web admin · 2026-06-18

## 📸 Scope
Redesigned mobile web admin สำหรับ Cloudflare Tunnel Manager — 5 หน้า (Tunnels/Dashboard, DNS, Logs, Settings, Setup) viewport 390×844 dark theme. รีวิวเพื่อยกระดับให้ดู **premium จริง** + ใช้งานได้ลื่นบนมือถือ ก่อนส่งต่อ frontend implement. โฟกัสของที่ทำให้ดูโปรขึ้นชัดๆ ไม่ใช่ nitpick.

โดยรวม foundation ดีมาก: palette near-black (`#09090b` / card `#18181b` / border `#27272a`) เป็น dark premium ที่ถูกทาง, radius สม่ำเสมอ (card `rounded-2xl`, button `rounded-xl`), touch target ส่วนใหญ่ ≥44px, มี safe-area-inset, skeleton loading + empty state ครบหลายหน้า. ปัญหาหลักไม่ใช่ "พื้นฐานพัง" แต่เป็น **3 จุดที่ฉุดให้ดูยังไม่เสร็จ**: (1) Dashboard เป็นกำแพงปุ่มเขียว 29 อันไม่มี hierarchy + ไม่มี search, (2) emoji icon + ปุ่ม disabled สีน้ำตาลขุ่นใน Settings, (3) ไม่มี font stack จริง (ใช้ system default).

---

## ✅ ของดีที่ควรเก็บไว้
- **Palette dark premium** — near-black + เลเยอร์ elevation บางๆ ทำได้ดี ไม่ใช่ grey เทาๆ ทั่วไป
- **Skeleton loading** บน Dashboard + Settings (`animate-pulse`) — ละเอียด ดูโปร
- **Empty states** — Dashboard ("ยังไม่มี Tunnel") + Logs ("กด เริ่ม Stream") มี copy + icon ครบ
- **Inline confirm delete** บน TunnelCard (ยืนยัน/✕) — ปลอดภัยกว่า dialog, ไม่ขัดจังหวะ
- **Status pill + pulse dot** บนการ์ด tunnel — affordance ชัด
- **safe-area-inset** บน nav + FAB — ใส่ใจ detail มือถือจริง
- **Active nav state** (สีส้ม + underline) — ตำแหน่งปัจจุบันชัด

## ➕ เพิ่ม

- **[Dashboard] Search + filter chips (all / running / stopped)** — มี 29 tunnels เรียงยาวเป็นพรืด หาตัวที่ต้องการต้อง scroll ทั้งจอ. เพิ่ม sticky search box ใต้ stats + chip filter. *impact: high*
  - before: รายการ 29 การ์ดไหลยาวอย่างเดียว
  - after: `<input>` กรองชื่อ + 3 chip (`rounded-full px-3 py-1 text-xs`) toggle running/stopped — ลด cognitive load มหาศาล

- **[Setup/Dashboard] รวม create flow ให้เหลือทางเดียว** — ตอนนี้มี 2 ทางสร้าง tunnel ที่ซ้อนกัน: FAB (`+`) เปิด `CreateTunnelModal` กับหน้า `/setup` ทั้งหน้า. `/setup` ยัง **ไม่อยู่ใน bottom nav** เลย → orphaned. เลือกทางเดียว (แนะนำ modal) แล้วลบ/redirect อีกทาง. *impact: high*

- **[Typography] เพิ่ม font stack จริง** — ตอนนี้เป็น system default → ทำให้ดู "ยังไม่เสร็จ". ใส่ Inter (latin) + Noto Sans Thai / IBM Plex Sans Thai (ไทย) ผ่าน `next/font`. นี่คือ **lever เดียวที่ยกระดับ premium ได้มากสุดต่อแรง**. *impact: high*

- **[DNS] leading icon ในแต่ละ action card** — การ์ดมีแค่ label+desc ดูแบนๆ. เพิ่ม SVG line icon นำหน้า (ตรวจสอบ=search, CNAMEs=list, แก้ไข=wrench, ล้าง=trash) ให้สแกนเร็วขึ้น + ดูเป็นระบบ. *impact: med*

- **[DNS] ใช้พื้นที่ว่างใต้ grid** — หน้า DNS มีการ์ด 4 อันบน เหลือพื้นที่ว่างครึ่งจอ. ใส่ hint card "ผลลัพธ์จะแสดงที่นี่" หรือ last-run summary เพื่อ balance. *impact: low*

- **[Header] ใช้พื้นที่ว่างฝั่งขวา** — header สูง 56px มี logo+title ฝั่งซ้าย เหลือขวาว่างทั้งแถบ. ใส่ contextual action (refresh บน Dashboard / connection status) จะดูตั้งใจขึ้น. *impact: low*

- **[Logs] filter bar (Error / Warn / Info)** _(gemini)_ — log บนมือถืออ่านยาก. เพิ่ม chip filter ระดับ log ด้านบน terminal เป็น must-have ของ admin tool จริง + ลงสีตาม level (แดง/เหลือง/เขียว) แทน emerald ล้วน. *impact: high*
  - file: `components/LogViewer.tsx`

- **[Dashboard] system-wide busy / progress overlay ตอน Start All / Stop All** _(gemini)_ — ถ้ากด "เริ่มทั้งหมด" แล้วสลับไปหน้า Logs ระหว่างนั้น ผู้ใช้ไม่รู้ว่ากำลังทำงานอยู่ (Nielsen #1). เพิ่ม top progress bar / global busy indicator. *impact: med*

- **[TunnelCard] copy-to-clipboard hostname** _(gemini)_ — หลัง route DNS เสร็จ เพิ่มไอคอน copy ข้างชื่อ hostname — บนมือถือ select+copy ลำบาก เป็น UX win ชัดๆ. *impact: med*

- **[Empty/Setup] template selector / getting-started** _(gemini)_ — empty state ตอนนี้ "ปลอดภัย" แต่ยังเรียบ. เพิ่ม illustration หรือ template chip (Static Web / Proxy / Cloudflared) ให้เริ่มต้นง่ายและดู premium ขึ้น. *impact: low*

## ➖ ลบ

- **[Settings] emoji icons (⚡ 🐳 ⚙️)** ใน Runtime Mode — ขัดกับ SVG line-icon system ที่ใช้ทั้งแอป (nav, การ์ด). โดยเฉพาะ 🐳 ดู toy-ish ฉุด premium. แทนด้วย SVG line icon ชุดเดียวกัน. *impact: high*

- **[Dashboard] hostname placeholder "cfd" ใต้ทุกการ์ด** — ทุก tunnel แสดง subtitle "cfd" เหมือนกันหมด → ดูเหมือน data พัง/placeholder ที่ลืมลบ. ถ้าไม่มี hostname จริงให้ **ซ่อนบรรทัดนี้** (มี guard `tunnel.hostname &&` อยู่แล้ว — ตรวจว่าทำไม "cfd" หลุดเข้ามา). *impact: high*

- **[Dashboard] น้ำหนักปุ่มเขียวบนทุกการ์ด** — 29 ปุ่ม solid emerald เต็มจอ = กำแพงเขียว ไม่มีอะไรเด่น ตาล้า. ไม่ใช่ลบปุ่ม แต่ลด "น้ำหนักภาพ": เปลี่ยน start เป็น ghost/outline emerald (`bg-emerald-500/10 border-emerald-500/30 text-emerald-400`) solid เฉพาะตอน hover. ให้สถานะ running เด่นแทน. *impact: high*

## 🔧 ปรับ

- **[Settings] ปุ่ม disabled สีน้ำตาลขุ่น** — `บันทึก` ใช้ `variant=primary` (orange) + `disabled:opacity-40` → ส้มจางเป็นน้ำตาลโคลน ดูเหมือน bug. แก้ที่ `Button.tsx`: disabled state ให้เป็น neutral (`disabled:bg-zinc-800 disabled:text-zinc-600 disabled:border disabled:border-zinc-700` แทน `opacity-40`). *impact: high*
  - file: `web/components/Button.tsx:23`

- **[ทั้งแอป] contrast ข้อความรอง/hint/placeholder** — `text-zinc-600` (#52525b) บน `#18181b` ได้ ~2.8:1 → **ตก WCAG AA**. ใช้กับ empty-state hint ("กด + เพื่อสร้าง"), placeholder (`เช่น my-app`, `sub.example.com`). เปลี่ยน body/hint เป็น `zinc-400` (#a1a1aa, ~7:1) และ placeholder เป็น `zinc-500` (#71717a, ~4.6:1). *impact: med*
  - files: `app/page.tsx:151`, `app/setup/page.tsx:45`, `components/TunnelCard.tsx:165`

- **[Dashboard] bulk-action row แน่นเกิน** — `เริ่มทั้งหมด` + `หยุดทั้งหมด` + badge `native` ยัด 3 ก้อนในแถวเดียว ปุ่มถูกบีบ. ย้าย mode badge ขึ้นไปอยู่ข้าง stats bar หรือใน header แล้วให้ 2 ปุ่มเต็มความกว้าง. *impact: med*
  - file: `app/page.tsx:102-126`

- **[Dashboard] ความหนาแน่นการ์ด** — แต่ละการ์ดสูง (name + host + แถวปุ่ม 44px) → 29 อัน = scroll ยาวมาก. พิจารณา compact layout: ชื่อ+status ซ้าย / ปุ่มกระชับขวา ในแถวเดียว ให้เห็นต่อจอมากขึ้น (ระวังคง touch target). *impact: med*

- **[Logs] มาตรฐานภาษาปุ่ม TH/EN** — ปนกัน: "เริ่ม Stream" / "หยุด" / "ล้าง" / "Disconnected" / "Connected". เลือกแนวเดียว (แนะนำ action เป็นไทยล้วน: "เริ่ม"/"หยุด"/"ล้าง", status เป็นไทย "เชื่อมต่อแล้ว"/"ตัดการเชื่อมต่อ" หรือคงอังกฤษทั้งคู่). *impact: low*
  - file: `components/LogViewer.tsx:48,67`

- **[Header] logo glyph เป็นรูปคน (silhouette หัว+ไหล่)** — อ่านเป็น "account/profile" ไม่ใช่ tunnel/network. เปลี่ยนเป็น network/link/globe glyph ให้สื่อ brand ตรง. กรอบส้ม rounded ดีอยู่แล้ว เก็บไว้. *impact: med*
  - file: `app/client-layout.tsx:67-69`

- **[Settings] ความเชื่อมโยง cloudflared ✗ ↔ Login Cloudflare** — cloudflared ขาด (✗) แต่ปุ่ม Login อยู่คนละ section ไม่มีเส้นเชื่อม. เมื่อ requirement สำคัญ fail ควร highlight ปุ่ม Login หรือมี inline CTA ใต้รายการที่ ✗. *impact: low*

- **[Dashboard] น้ำหนักภาพ stats bar** _(gemini)_ — ตัวเลข `text-2xl font-bold` 3 ก้อน อาจเด่นเกินจนกลบ content บนจอเล็ก. ลดเป็น `text-xl` หรือเพิ่ม contrast label↔value แทนการเพิ่มขนาด. *impact: low*
  - file: `app/page.tsx:86-97`

- **[Dashboard] running card ให้ "pop" กว่าเส้นข้าง 4px** _(gemini)_ — ตอนนี้ running แยกด้วย `border-l-4 border-l-emerald-500` อย่างเดียว. เพิ่ม gradient bg จางๆ หรือ `shadow-glow-green` (มีใน config แล้ว) ให้การ์ดที่ทำงานอยู่เด่นจากกองที่หยุด. *impact: med*
  - file: `components/TunnelCard.tsx:52-56`

- **[FAB] ตำแหน่งชน Tunnels tab / gesture bar** _(gemini)_ — FAB อยู่ขวาล่างเหนือ nav; บนเครื่อง gesture-bar อาจเบียดไอคอน/ขอบจอ. เพิ่ม margin จาก safe-area-inset ให้เผื่อมากขึ้น. *impact: low*
  - file: `app/page.tsx:164`

## 🚩 Heuristic violations (Nielsen)

- **#6 Recognition rather than recall** — Dashboard 29 tunnels ไม่มี search/filter → ผู้ใช้ต้องจำว่าตัวไหนอยู่ตรงไหนแล้วไล่หาเอง. แก้: search + filter chips (ดู ➕ ข้อแรก)
- **#8 Aesthetic & minimalist design** — กำแพงปุ่มเขียว 29 อัน + subtitle "cfd" ซ้ำทุกการ์ด = visual noise ไม่มี signal. แก้: ghost start button + ซ่อน hostname ปลอม
- **#4 Consistency & standards** — (a) emoji vs SVG icon, (b) 2 create flow (modal + /setup), (c) TH/EN ปนในปุ่ม Logs. แก้: unify ทั้ง 3
- **#1 Visibility of system status** — disabled `บันทึก` สีน้ำตาลขุ่น สื่อสถานะผิด (ดูเหมือน error ไม่ใช่ "ยังไม่มีอะไรเปลี่ยน"). แก้: neutral disabled style
- **#5 Error prevention** — มีแล้ว (inline confirm delete) ✅ เก็บไว้
